# Excel VBA Sales Report Automation

An Excel VBA project that automates sales summaries, regional sales analysis, dashboard formatting, chart creation, and PDF report export.

## Features
- Automated sales summary report
- Total revenue, total orders, and quantity sold
- Region-wise sales analysis
- Automatic chart generation
- Dashboard refresh button
- PDF report export

## Tools & Skills
- Microsoft Excel
- VBA (Visual Basic for Applications)
- Excel Formulas
- Data Analysis
- Dashboard Design
- Report Automation

## Project File
`Sales_Report_Automation.xlsm`

## How to Use
1. Download the Excel workbook.
2. Open it in desktop Microsoft Excel.
3. Enable macros if you trust the file.
4. Open the SalesSummary sheet.
5. Click **REFRESH SALES** to update the report.
